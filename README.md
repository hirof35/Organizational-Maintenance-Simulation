Organizational Resilience Simulator
組織の構造的差異（自律型 vs 依存型）が、パニック（ノイズ）の伝播や外敵に対する生存率にどのような影響を与えるかを可視化するシミュレーターです。

🔬 シミュレーションの概要
このプロジェクトでは、以下の2つの組織モデルを比較・検証します。

自律型 (Autonomous Mode)

各エージェントが周囲の個体との距離や速度を調整し、群れ（Boidsアルゴリズムをベースとした論理）を形成します。

「批判的思考（Critical Thinking）」のパラメータにより、周囲の異常な動き（パニック）に同調するか、個別の判断を下すかが変化します。

依存型 (Dependency Mode)

すべてのエージェントが単一の「リーダー（Leader）」を追従します。

リーダーの挙動が組織全体の運命を決定する、中央集権的な構造です。

🚩 主要な要素
Agent (エージェント): 組織の構成員。

Healthy (緑/青): 正常に機能している個体。

Panicked (オレンジ): 異常値。スパイの影響や周囲の混乱に巻き込まれた状態。

Spy (赤): 組織内に意図的にパニック（攪乱）を引き起こす外部因子。

Enemy (赤い円): 組織を脅かす外敵（マウスカーソルで操作）。接触するとエージェントは消滅します。

⚙️ パラメータ制御
Conformity (同調性): 周囲の動きにどれだけ合わせるか。高いほどパニックが連鎖しやすくなります。

Critical Thinking (批判的思考): 周囲の個体の速度が異常な場合、その個体への同調を拒否する能力。

CSV Logging: 1秒ごとに生存数やパニック数を記録し、後で統計解析（Excel等）が可能です。

📈 設計思想：思想工学と「自灯明」
本シミュレーターは、エンジニアリングにおける「自灯明（Self-Lighting）」の重要性を検証するために設計されました。
外部のリーダーや強いバイアス（同調圧力）に依存するシステムがいかに脆く、個々の論理的自律性が組織のレジリエンス（回復力）にどう寄与するかを数学的にモデル化しています。
